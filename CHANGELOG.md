# Changelog

All notable changes to `laravel-presentable` will be documented in this file

## 1.5.0 - 2026-03-24

- Add support for Laravel 13
- Update minimum PHP version requirement to 8.3
- Add PHPUnit 12 support
- Add Orchestra Testbench 11 support
- Update CI matrix to test against PHP 8.3, 8.4, and 8.5

## 1.4.0 - 2025-08-25

- Add support for Laravel 12
- Update minimum PHP version requirement to 8.2
- Modernize type hints and method signatures
- Update PHPUnit tests to use modern attributes instead of deprecated annotations
- Update test dependencies to support PHPUnit 11

## 0.2.0

- Update support for Laravel Framework v9

## 0.0.1

- Initial release
